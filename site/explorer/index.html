Explorer

Each seed node keeps the whole chain and has a block explorer of its own. Pick any of them: they should all show the same thing.

Network shown: the development network (devnet). Its coins have no value, and it may be wiped at any time. The CVN Testnet has not started.

Asking the seeds…

SeedHeightNewest blockRaces

This page asks each seed directly from your browser, every 30 seconds. A seed that is a block behind for a moment is normal. "Races" counts the heights at which that seed saw two valid blocks compete, since it last started.

Reading it

  • Height is how many blocks the seed holds.
  • Newest block is the start of that block's identifier. Seeds at the same height should show the same one.
  • The seeds are run by the project's maintainer. None of them mines, and none has any say over the rules: every node checks every block for itself.
